# Vendor Variants - Remediating Gcp Vpc Network Misconfiguration

Vendor-specific implementations, feeds, and collectors for this procedure.


## Prisma Cloud Remediation - GCP VPC Network Misconfiguration

**Product:** Prisma Cloud by Palo Alto Networks

**Kind:** playbook

This playbook remediates Prisma Cloud GCP VPC Network alerts. It calls sub-playbooks that perform the actual remediation steps. Remediation

**Inputs:**

- `AutoRemediateVPCNetwork`: Execute GCP Compute Engine remediation automatically?
- `policyId`: Grab the Prisma Cloud policy ID.

**Dependencies:**

- Sub-playbooks: Prisma Cloud Remediation - GCP VPC Network Project Misconfiguration, Prisma Cloud Remediation - GCP VPC Network Firewall Misconfiguration
- Integrations: Builtin, PrismaCloud v2
- Commands: redlock-dismiss-alerts, closeInvestigation
