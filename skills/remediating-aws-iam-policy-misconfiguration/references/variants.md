# Vendor Variants - Remediating Aws Iam Policy Misconfiguration

Vendor-specific implementations, feeds, and collectors for this procedure.


## Prisma Cloud Remediation - AWS IAM Policy Misconfiguration

**Product:** Prisma Cloud by Palo Alto Networks

**Kind:** playbook

Remediates Prisma Cloud AWS IAM policy alerts. It uses sub-playbooks that perform the remediation steps

**Inputs:**

- `AutoUpdatePasswordPolicy`: Whether to update AWS IAM password policy automatically.
- `policyId`: Returns the Prisma Cloud policy ID.

**Dependencies:**

- Sub-playbooks: Prisma Cloud Remediation - AWS IAM Password Policy Misconfiguration
- Integrations: PrismaCloud v2, Builtin
- Commands: closeInvestigation, aws-iam-get-account-password-policy, redlock-dismiss-alerts
