# Vendor Variants - Conducting Post Incident Lessons Learned

Vendor-specific implementations, feeds, and collectors for this procedure.


## NIST - Lessons Learned

**Product:** NIST

**Kind:** playbook

This playbook assists in processing an incident after it occurs and facilitates the lessons learned stage, as described in the ‘Handling an Incident’ section of NIST - Computer Security Incident Handling Guide

**Inputs:**

- `DataCollection`: Use a data collection task to answer lessons learned questions based on NIST. Specify 'True' to automatically send the communication task, and 'False' to prevent it.
- `Email`: Email address to which to send the questions.
