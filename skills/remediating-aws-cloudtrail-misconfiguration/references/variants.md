# Vendor Variants - Remediating Aws Cloudtrail Misconfiguration

Vendor-specific implementations, feeds, and collectors for this procedure.


## Prisma Cloud Remediation - AWS CloudTrail Misconfiguration

**Product:** Prisma Cloud by Palo Alto Networks

**Kind:** playbook

This playbook remediates Prisma Cloud AWS CloudTrail alerts. It calls sub-playbooks that perform the actual remediation steps. Remediation

**Inputs:**

- `AutoUpdateCloudTrail`: Update AWS CloudTrail automatically?
- `policyId`: Get the Prisma Cloud policy ID.

**Dependencies:**

- Sub-playbooks: Prisma Cloud Remediation - AWS CloudTrail Is Not Integrated With CloudWatch Logs, Prisma Cloud Remediation - AWS CloudTrail is not Enabled on the Account, Prisma Cloud Remediation - AWS CloudTrail Trail Misconfiguration
- Integrations: PrismaCloud v2
- Commands: redlock-dismiss-alerts, closeInvestigation
