# Vendor Variants - Acquiring Host Forensics

Vendor-specific implementations, feeds, and collectors for this procedure.


## Get host forensics - Generic

**Product:** Common Playbooks

**Kind:** playbook

This playbook retrieves forensics from hosts for the following integrations

**Inputs:**

- `fqdn_or_ip`: If using the Illusive Networks integration to retrieve additional forensics, provide the host fqdn_or_ip from which to get the forensics.
- `start_date`: Date_range must be "number date_range_unit", for example 2 hours, 4 minutes, 6 months, 1 day.
- `end_date`: Date_range must be "number date_range_unit" for example 2 hours, 4 minutes, 6 months, 1 day.
- `machine_ID`: Provide the machine IDs of the systems you want to retrieve.

**Dependencies:**

- Sub-playbooks: Illusive-Collect-Forensics-On-Demand, Microsoft Defender For Endpoint - Collect investigation package
- Scripts: IsIntegrationAvailable
