# Vendor Variants - Remediating Azure Storage Misconfiguration

Vendor-specific implementations, feeds, and collectors for this procedure.


## Prisma Cloud Remediation - Azure Storage Misconfiguration

**Product:** Prisma Cloud by Palo Alto Networks

**Kind:** playbook

This playbook remediates Prisma Cloud Azure Storage alerts. It calls sub-playbooks that perform the actual remediation steps. Remediation

**Inputs:**

- `AutoRemediateAzureStorage`: Execute Azure Storage remediation automatically?
- `policyId`: Grab the Prisma Cloud policy Id.

**Dependencies:**

- Sub-playbooks: Prisma Cloud Remediation - Azure Storage Blob Misconfiguration
- Integrations: PrismaCloud v2
- Scripts: IsIntegrationAvailable
- Commands: closeInvestigation, redlock-dismiss-alerts
